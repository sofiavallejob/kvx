# kvx

Data for Pure Data vanilla (0.54 and newer): a JSON dictionary, a player for
CSV, NumPy and JSON Lines files, a buffer for live data, and a Python client.
Plain C with no dependencies, built for Linux, macOS (Intel and Apple Silicon)
and Windows.

Pd has no built-in way to keep nested data, to read a big CSV without first
turning it into a text file, or to take a live feed from Python. These are
things people keep asking for on the Pd forum, the pd-list and Reddit, and in
papers about sonification tools (a data player you can scrub, live streams,
easy mappings). kvx tries to make them one message away.

| Object | What it does |
| --- | --- |
| `kvx/dict` | A named dictionary of numbers, words, lists and objects (the shape of JSON). Reads and writes JSON files. Objects with the same name share one dictionary. Answers requests from other programs. |
| `kvx/table` | Reads CSV, TSV, NumPy (`.npy`) and JSON Lines (`.jsonl`) files. Columns are kept as numbers, so millions of rows stay small. Plays the rows at a rate or by their own time stamps, with speed, loop and scrubbing; scales columns to a range; copies them into Pd arrays; thins them out keeping the peaks; adds computed columns; records rows from Pd and writes CSV. |
| `kvx/stream` | A ring buffer for live data from Pd or Python: the newest row, statistics of the last n rows, the last n values into an array. |
| `pdkv` (Python) | `pip install ./python`. Read and write the dictionary, push rows to a stream, write `.csv`/`.npy` files for Pd, turn an ObsPy stream into a CSV. No dependencies. |

## Examples

The `examples` folder has twelve patches that work out of the box. Open them
from the library folder, so they find their data files.

| Patch | What it shows |
| --- | --- |
| `01-presets.pd` | Sound settings in a JSON file, chosen with a message. |
| `02-explore-csv.pd` | Read a CSV, ask about columns and statistics, look at single rows. |
| `03-play-rows.pd` | Every row of a seismogram becomes a note. |
| `04-audification.pd` | One column copied into an array and played as audio. |
| `05-european-csv.pd` | Files with semicolons and decimal commas. |
| `06-python-live.pd` | Python drives a sound through the dictionary (`python_demo.py`). |
| `07-data-player.pd` | Three years of climate data played by date: pause, speed, loop, jump to a year, scrub. |
| `08-audification-lab.pd` | Four data sets (CSV, NumPy, JSON Lines) in stereo, from slow shapes to fast waveforms, backwards too. |
| `09-mapping.pd` | Parameter mapping: smoothed temperature picks notes of a pentatonic scale, rainy days play drums. |
| `10-live-stream.pd` | Python streams a sensor log live into `kvx/stream` (`python_stream_demo.py`). |
| `11-formats-and-saving.pd` | NumPy and JSON Lines, thinning out, cutting by time, writing a CSV. |
| `12-record-gesture.pd` | Record two sliders into a table, play them back, save them. |

The data files (`quakes.csv`, `climate.csv`, `sensors.jsonl`, `signal.npy`)
are made up for the examples, not real measurements. The examples are
generated by `tools/build_examples.py`.

## kvx/table in short

```
[read quakes.csv -stride 10 -cols time ch1(     every 10th row, two columns
[range ch1 48 72(                                 ch1 comes out as notes 48..72
[play -time 50(                                   follow the time column, 50 x real time
[toarrays ch1 left ch2 right norm(                columns into Pd arrays, scaled to -1..1
[decimate 10 minmax ch1(                          one tenth of the rows, peaks kept
[write short.csv(                                 save it
```

| Message | |
| --- | --- |
| `read file [options]` | CSV/TSV, or `.npy` and `.jsonl` by their ending. `-stride n`, `-maxrows n`, `-skip n`, `-cols a b 3` (names or numbers from 0), `-delim comma\|semicolon\|tab`, `-decimal point\|comma`, `-header 0\|1`, `-reltime 0\|1`. Read row by row. |
| `write file [cols]`, `append v ...`, `clear` | Save as CSV (dates written as dates), add a row, empty. |
| `columns`, `rows`, `get row col`, `row n`, `stats col` | Questions and values. Rows and columns count from 0. |
| `range col lo hi`, `range col off`, `range off`, `nan value` | Scale a column on its way out; what empty cells come out as (default 0). |
| `toarray col array [norm]`, `toarrays col array ... [norm]`, `fromarray newcol array` | To and from Pd arrays. |
| `derive col [name]`, `smooth col n [name]`, `decimate n [first\|mean\|minmax col]`, `crop start count`, `crop -time from to` | Computed columns and fewer rows. |
| `bang`, `play [ms]`, `play -time [speed] [col]`, `pause`, `speed n`, `loop 0\|1`, `reset`, `seek row`, `at seconds`, `pos 0..1` | The player. The right outlet gives the position from 0 to 1. |

Dates such as `2024-03-05T10:20:30Z` become seconds counted from the first row
(a 32-bit Pd float cannot hold a whole date); the start comes out as
`timeorigin col seconds`. The first line is taken as a header when it has words
where the next line has numbers, or only words; force it with `-header 1` or
`-header 0`.

## kvx/dict in short

```
[read patch-settings.json(          load a file next to the patch
[get synth.partials(                -> a list: 1 2 3 5
[set synth.freq 440(                change one value, keep the rest
[write patch-settings.json pretty(  save it back
```

Paths: `a.b.c` goes down into objects, `list.0` or `list[0]` picks an item.

| Message | |
| --- | --- |
| `set path v ...` | One value is a number or word, several make a list. |
| `setjson path text`, `json text` | JSON text into a path, or replacing everything. |
| `setnull path`, `setbool path 0/1` | The two values Pd has no atom for. |
| `get [path]`, `tojson [path] [pretty]`, `print [path]`, `bang` | Read. Plain values and flat lists come out as Pd messages, anything nested as `json <text>`. |
| `has`, `type`, `keys`, `size` | Questions about a path, answered on the middle outlet. |
| `push path v ...`, `del path`, `clear` | Append to a list, remove, empty. |
| `read file`, `write file [pretty]` | JSON files (relative to the patch). |
| `req id message ...` | Run a message and answer on the right outlet as `send reply id ...`, ready for `[netsend]`. Used by Python. |
| `jsonbuf text`, `jsonapply [path]` | JSON text in pieces, for values longer than one message can carry. |

Pd never frees symbols, so for big data that changes all the time use `read`
and `write` instead of passing JSON text around.

## kvx/stream in short

`[kvx/stream 3 2000]` keeps the newest 2000 rows of 3 columns. `push v ...` (or
a list) adds rows, `bang` gives the newest, `get k` an older one, `stats col [n]`
the statistics of the last n, `toarray col array [n] [norm]` copies the last n
values into an array, `thru 1` passes every new row out.

## Python

```python
import pdkv
pd = pdkv.Client()                       # Pd: [netreceive 9001] -> [kvx/dict name] -> [netsend]
pd["synth.freq"] = 220
pd.get("synth.freq")
pd.push_rows([[0.1, 0.5, 0.8]])          # Pd: [netreceive 9001] -> [route stream] -> [kvx/stream 3]
pd.send("synth", "freq", 440)            # any message, for [route synth]

pdkv.save_csv("data.csv", {"time": times, "x": xs})   # files kvx/table reads
pdkv.save_npy("data.npy", {"x": xs, "y": ys})
pdkv.from_obspy(stream, "quake.csv")                  # ObsPy Stream -> CSV with a time column
```

`from_obspy` was tested with stand-in objects, not with ObsPy itself.

## Install

In Pd: Help > Find externals, search `kvx`. Or download the package from the
Actions tab of the repository and unzip the `.dek` file (it is a zip) into
your externals folder, so you get a `kvx` folder with the binaries in it.

Do not add `-lib kvx` to Pd's startup flags: the objects load by their names,
`[kvx/dict]`, `[kvx/table]`, `[kvx/stream]`.

macOS: the binaries are signed "ad hoc" (no Apple developer account), which is
enough for Apple Silicon. If macOS still blocks them after a browser download,
run once in Terminal:

```
xattr -dr com.apple.quarantine ~/path/to/externals/kvx
```

Python: `pip install ./python` from the kvx folder.

## Build

Needs the Pd source (for the headers) and pd-lib-builder (included):

```
git clone --depth 1 https://github.com/pure-data/pure-data.git pd
make PDINCLUDEDIR=pd/src
make test                              # JSON, CSV, NumPy, JSON Lines, no Pd needed
make test-object PDINCLUDEDIR=pd/src   # the dictionary object, with a mock instead of Pd
python -m unittest discover -s python/tests
```

Every push builds Linux, macOS and Windows binaries on GitHub Actions and
makes a ready deken package (Actions tab, artifact `kvx-deken`). The help
files are generated by `tools/build_help.py`, the examples by
`tools/build_examples.py`.
